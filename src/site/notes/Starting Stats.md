# Starting Stats

On your **first join** the plugin sets your stats below vanilla. This table shows each change and which upgrade wins it back.

| Stat | Vanilla | Leveling start | How to improve |
|---|---|---|---|
| Max health | 20 HP (10 ❤) | **10 HP (5 ❤)** | [[Skills/Defense Skill\|Defense Skill]] → Base Health · Tank class |
| Base attack damage | 2 | **1** (all weapons hit 1 less) | [[Skills/Combat Skill\|Combat Skill]] → Attack Damage · Melee class |
| Attack speed | 4.0 | **3.1** | [[Skills/Combat Skill\|Combat Skill]] → Attack Speed |
| Walking speed | 0.10 | **0.05 (half)** | [[Skills/Movement Skill\|Movement Skill]] → Movement Speed |
| Block breaking speed | 100% | **75%** | (no upgrade) |
| Mining efficiency (correct tool) | 0 | 1 | [[Skills/Mining Skill\|Mining Skill]] → Mining Speed |
| Underwater mining | 0.2 | **0.1 (half)** | [[Skills/Fishing Skill\|Fishing Skill]] → Submerged Mining Speed |
| Extra air underwater | 0 | 0 | [[Skills/Fishing Skill\|Fishing Skill]] → Oxygen Bonus |
| Burning time | 100% | **200%** | [[Skills/Brewing Skill\|Brewing Skill]] → Burning Time |
| Food-based natural regen | 100% | **25%** | [[Skills/Defense Skill\|Defense Skill]] → Regeneration Food · Tank class |
| Regeneration-effect healing | 100% | **25%** | [[Skills/Defense Skill\|Defense Skill]] → Regeneration Potion · Tank class |
| Inventory | 36 slots | **9 slots (hotbar)** | [[Skills/Inventory Skill\|Inventory Skill]] → Unlock Slots |
| Armor | any | **none** | [[Skills/Mining Skill\|Mining Skill]] → Armor Level |
| Elytra | usable | **locked** | [[Skills/Movement Skill\|Movement Skill]] → Elytra Unlock |
| Vanilla XP orbs | 100% | 100% | [[Skills/Enchanting Skill\|Enchanting Skill]] → EXP Gain |

**Starter kit:** 16 Cooked Beef (Steak).

> [!NOTE]
> These values are applied **once**, on your very first join. Later resets inside the menu put the stat back to these starting values, not to vanilla.
